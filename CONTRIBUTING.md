# Contributing to FLUFFY

Thank you for your interest in contributing to **FLUFFY — Your Little World of Fluff**!

1. Fork the repository and create a feature branch (`git checkout -b feat/new-accessory`).
2. Ensure all 3D geometry is built procedurally using Three.js primitives and WebGL2 shaders (no external proprietary 3D models).
3. Verify zero console errors in both Desktop and Mobile Portrait views.
4. Submit a Pull Request!
