## Reporting a Vulnerability

If you discover a potential security vulnerability within **FLUFFY**, please do not create a public issue.
Instead, report the issue privately to:

**Teja Priyan**: `teja1616150@gmail.com`

Please include detailed steps to reproduce the vulnerability. You will receive an acknowledgment within 48 hours.
