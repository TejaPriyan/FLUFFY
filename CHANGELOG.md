# Changelog

All notable changes to this project will be documented in this file.

## [12.0.0] - 2026-10-31

### Added
- Real-time 3D WebGL2 & Three.js pet simulation engine with 38,000 instanced hair filaments.
- 64 Verlet / spring physics guides responding to movement across 5 body zones.
- Interactive 3D Hair Salon (`Trim (X)`, `Grow (G)`, `Dryer (D)`, Ombré styling).
- Wet-Fur dynamic clump physics and 3D bath foam bubbles.
- Autonomous toys: 3D Yarn Ball with physics bouncing and 3D Laser Pointer.
- Web Audio API chiptune sound synthesis with musical dance party mode.
- 9 procedural accessories and cozy quilted pet bed.
- Responsive Desktop and Mobile Portrait modes.
- Complete standalone offline bundle (`fluffy.html`) and offline PWA service worker.
